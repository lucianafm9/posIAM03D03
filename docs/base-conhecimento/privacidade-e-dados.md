# Privacidade e proteção de dados de saúde

## Dados de saúde são dados sensíveis
Pela Lei Geral de Proteção de Dados (LGPD, Lei 13.709/2018), informações de saúde são dados pessoais sensíveis. A AuroraMed só compartilha dados de saúde com o próprio titular ou com o responsável legal por beneficiários menores de idade.

## Acesso ao prontuário e a resultados
O titular pode acessar o próprio prontuário e os resultados de exames pelo app AuroraMed, após login. Pedidos de cópia do prontuário completo são atendidos em até 15 dias pela Central de Atendimento. Dados de outra pessoa, inclusive familiares maiores de idade, só podem ser acessados pela própria pessoa ou com procuração.

## Encarregado de dados
Solicitações sobre dados pessoais (acesso, correção, exclusão ou revogação de consentimento) podem ser enviadas ao Encarregado de Dados pelo e-mail privacidade@auroramed.example.

## Segurança no atendimento
A AuroraMed nunca solicita senha do app por telefone, e-mail ou chat. Não compartilhe CPF, número da carteirinha ou resultados de exames em canais não oficiais.
